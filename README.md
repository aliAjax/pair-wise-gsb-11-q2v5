# 油站异常交接台

- 行业：石油
- 技术栈：React、Vite、TypeScript（数据保存在浏览器 localStorage，不新增任何依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- 登记异常：设备、区域、异常情况、发现班次（白班 08:00–20:00 / 夜班 20:00–次日 08:00）、责任人、复查时限。
- 同设备去重：同一设备存在未销项异常时禁止重复登记，表单即时提示责任人。
- 交班带入：点击「交班给下一班」后，所有未销项自动带到下一班并累计交接次数；页面跨班打开也会自动补齐带入。
- 超期待办：超过复查时限的异常始终排在待处理最前并标红，每 30 秒刷新倒计时。
- 销项权限：仅责任人本人或站长可以销项，销项前必须填写处理说明；已销项保留处理人、时间与说明。
- 操作人：右上角选择当前值班员/站长，身份保存在浏览器本地。
- 旧数据迁移：首次打开自动把旧版巡检清单中的「异常」项迁移为未销项记录。

## 目录结构

- `src/data/`：数据模型、区域/设备目录、初始演示数据
- `src/rules/handover.ts`：交接规则纯函数（班次换算、登记校验、交班带入、超期判断、销项权限）
- `src/storage/repo.ts`：localStorage 持久化与旧数据迁移
- `src/hooks/useHandoverDesk.ts`：状态编排（规则 + 存储 + 定时刷新）
- `src/components/`：登记表单、异常卡片、交班栏、操作人栏
- `src/pages/HandoverDesk.tsx`：页面装配
