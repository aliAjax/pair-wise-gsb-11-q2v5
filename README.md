# 油站异常交接台

在原"油站设备巡检清单"（每项只记状态）基础上扩展的异常交接闭环：夜班发现的异常登记设备、区域、发现班次、责任人和复查时限，交班时未销项自动带到下一班，解决"下一班不知道谁跟进、是否处理完"的问题。

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand（不增加新依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 交接规则

1. 登记异常需填写：设备、区域、异常现象、责任人、复查时限。
2. 同一设备只要存在未销项异常，不能再建一条（表单与规则层双重拦截）。
3. 点击"交班"后，全部未销项自动带到下一班并更新跟进班次，已销项不动；交班动作留痕（带入条数）。
4. 超过复查时限仍未销项的，继续排在待处理列表最前并标红"超期未处理"。
5. 责任人本人或站长可以销项，销项前必须填写处理说明（处理措施、复查结果留痕）。
6. 跨班次重新打开页面时，按系统时间自动把未销项追到当前实际班次。

## 目录分层

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 清单数据（类型与目录） | `src/data/` | 异常、班次、交班事件类型；区域/设备/责任人候选数据 |
| 交接规则 | `src/rules/handover.ts` | 班次推算、防重登记、交班结转、销项权限、超期判断（纯函数） |
| 持久化 | `src/storage/deskStorage.ts` | localStorage 读写、版本校验、演示种子数据 |
| 状态编排 | `src/store/deskStore.ts` | Zustand store，串联规则与持久化 |
| 页面 | `src/components/`、`src/App.tsx` | 登记表单、班次头部、待处理看板、交班记录、销项弹窗 |
| 配置 | `src/config/shiftConfig.ts` | 班次时段（08:00-20:00 / 20:00-08:00）、存储键 |

数据仍只保存在浏览器 localStorage（键：`dfwlfront-10-handover-desk`），刷新不丢失，页脚可重置演示数据。
